C-18

A janela do aplicativo é o controle. Esta página descreve a API local para outros sistemas.

Aplicar um perfil usa POST /api/apply. Polling aceita 125, 250, 500 e 1000 Hz.

curl -s http://127.0.0.1:8765/api/capabilities

curl -s -X POST http://127.0.0.1:8765/api/apply \
  -H 'Content-Type: application/json' \
  -d '{"perfil":1,"hz":1000,"luz":{"modo":"padrao","nivel":1,"brilho":10,"velocidade":10,"cor":"#c45c26"},"dpi":[15,25,40,70,100]}'

Sem luz e sem dpi, o pedido só grava perfil e polling.
